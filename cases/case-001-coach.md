## 下一次怎么继续

先补全原因讲解，再问用户：用中文描述允许购买的数量条件，以及失败时库存应怎样。等待回答后给最小修复对照：

```java
public boolean purchase(int quantity) {
    if (quantity <= 0 || quantity > stock) {
        return false;
    }
    stock -= quantity;
    return true;
}
```

不要先把这份教练记录作为答题提示。检查负数、零、普通购买、恰好库存、超库存及连续购买；各组从什么状态开始须明确。拒绝非法数量时库存保持不变。验证可手算，没运行不得称实测通过。
