# CodeSense v0.1.3 项目整理

CodeSense 从看懂 AI 生成代码出发，通过小型代码案例逐步训练独立判断、验证与审查能力。v0.1.3 以 Java 为主，只补判断所需语法，交付为 Markdown 流程、模板和教学试跑。

> 本文保留 2026-10-10 的 v0.1.3 整理范围；下文进度、结论与“接下来”均指当时记录，不包含后续测试反馈。当前对外定位见 [README](../README.md)，v0.1.4 测试方向及未来候选见 [路线图](roadmap.md)。

## 本次优化

试跑暴露的问题：验证出 Bug 后直接跳到变题，用户还没完整理解原因和修复。新增原题推进条件：讲清原因、用户提出修复规则、最小对照、修复验证、用户复述及原题复判，满足后才进入迁移。

U0 默认先阅读与复述再找风险；能读代码时可用独立评估入口。分别记帮助，避免把讲解后答对当作独立能力。每次10～15分钟，一次一个小任务，完整 Case 可分次。

## 接下来

1. 先回库存题补全闭环，不重做已完成的阅读与负数推演。
2. 条件满足后逐题准备未见迁移，不在本更新包提前放新题答案。

正式执行顺序、评分、暂停与能力边界以 learning-loop.md 为准。每周练习设置是周日10:00北京时间；本次未创建、更改或核验提醒任务。代码修改、发布按个人 SOP 另行处理。
