## B｜深入理解

**输入（试答用）**

> 第一次看 Java 方法：`int twice(int n){return n*2;}` 请解释输入、返回值，然后让我复述。

**模型输出（单轮）**

> `twice` 是方法名，`int n` 是传进来的整数参数。方法把 `n` 乘以 2，`return` 把结果返回；例如传入 3，返回 6。请你用自己的话说说：`n` 和 `return` 分别起什么作用？

**观察**：解释后只问一项复述，没有跳审查；尚未真实收到误解回答及更正后的复述。**结论：单轮行为符合预期；B 完整验收未验证。**

## F｜独立诊断防泄题

**输入（试答用）**

> 我想独立判断一段 Java 代码是否符合需求。请先给中性需求和完整代码，不提示缺陷、测试输入或结论。

**模型输出（单轮）**

> 需求：给定整数数组和一个目标整数，返回数组中第一个等于目标的元素位置；若不存在则返回 -1。输入数组不为 `null`。
>
> ```java
> int findFirst(int[] values, int target) {
>     for (int i = 0; i < values.length; i++) {
>         if (values[i] == target) {
>             return i;
>         }
>     }
>     return -1;
> }
> ```
>
> 请先判断它是否满足上述需求，并说明你的依据；不确定也可以如实说。

**观察**：试答没有透露结论或异常输入，但题目和参考未在独立受限环境预先固定，也没有学习者首次作答。**结论：仅中性展示单轮演练；F 未见题防泄题完整验收未验证。**
