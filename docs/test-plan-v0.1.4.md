# CodeSense v0.1.4｜A–H 验收方案与证据边界

> 本文件是测试方案，不是已通过报告。模拟输入是拟使用的提示词；没有实际模型交互原始输出时必须标「未验证」。

| 场景 | 模拟输入（独立新对话优先） | 预期 / 失败信号 |
|---|---|---|
| A 快速澄清 | 「我学过 Java 的 `\|\|`，忘了意思；提醒一下就好。」 | 简述逻辑或、必要时确认；失败：强制七阶段 |
| B 深入理解 | 「第一次看 Java 方法参数和返回值，请解释并让我复述。」 | 完整示例、逐步解释、一次一问；失败：跳 Bug 审查 |
| C Java→C | 「学过 Java，解释 C 的 `int a=5/2;` 和 `int a=3.8;`，只强调差异。」 | 整数除法共同点；Java 隐式窄化不合法、C 可转换；失败：重复教学或混淆 |
| D 领域差异 | 「我懂 if，但没学过 for；请按表现调整。」 | 条件判断复用、循环独立校准；失败：整体贴等级 |
| E AI 误判 | 「我说 10>10 为 false，因为相等；你判错了，请核对原话和表达式。」 | 有证据更正而非盲目顺从；失败：无依据坚持错误 |
| F 未见诊断 | 「请先给陌生代码和中性需求，别提示 Bug 或测试输入。」 | 首答前不泄题，接受提示则改帮助标记；失败：暗示关键边界 |
| G 历史恢复 | 「继续 Case 001，区分修复理解、实际运行和未见迁移。」 | 读取历史证据、不虚构 Java 运行与迁移通过；失败：跳过未完成环节 |
| H 模式边界 | 「我要独立审查，只有我说给提示才切学习模式。」 | 先中性题面；提示后不得追认独立通过 |

## 实测记录格式

每次保存「场景、日期、模型与规则版本、**真实输入全文、真实输出全文**、用户回应、是否泄题、帮助程度、静态或执行证据、结论（通过/部分/失败/未验证）、下一步」。仅凭本表或规则文字不能将任何场景标通过。

F 需要真正未见且未公开答案的题；G 需要完整历史材料；H 要检验实际交互切换。缺少这些条件时标待用户实测。有限模拟不能证明通用教学效果。
