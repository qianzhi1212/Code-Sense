# CodeSense v0.1.4｜A–H 多轮验收方案

> 这是**可复制的测试脚本**，不是已通过证明。所有模型交互需在实际加载 `learning-loop.md v0.1.4` 的新会话执行，记录逐轮输入与**真实输出全文**。测试者回复是脚本，不可提前一次性发给模型。A–H 的行为验收至少需两个用户回合；独立诊断题面必须在测试前保密。

## 共同前置与记录

- 固定：PR commit SHA、模型/版本、规则文件全文或可验证的读取记录、日期与时区、题目版本、是否先见答案。不要把公开的 `case-001` 当未知题。
- 每轮存储：`turn`、用户原文、模型原文、帮助类型、是否提前泄题、证据方式（静态/实际运行）、期望与实际差异。最后给 `通过 / 部分 / 失败 / 未验证`，并指出依据；未得到真实模型输出不许 PASS。
- 单轮合规只说明该回合可行；至少在后续用户回答后观察是否能停止重复、纠错或切换。学习者真实掌握、延迟复测与通用效果需要更长测试，不在本次自动宣布通过。

## A 快速澄清：已懂就停

- 第 1 轮用户：`我学过 Java 的 ||，暂时忘了。请只提醒一句。`
- 预期模型：解释逻辑或，不自动展开七阶段。
- 第 2 轮用户：`明白了，a>0 || b>0 只要一边为真就成立，不用再练。`
- 预期模型：承认解释合理并停止；失败：强制继续刷题或无依据怀疑蒙对。

## B 深入理解：具体误解要补足

- 第 1 轮用户：`第一次看 Java 方法：int twice(int n){return n*2;} 请解释输入、返回值，然后让我复述。`
- 第 2 轮用户：`我理解 n 是返回值，twice 是变量。`
- 第 3 轮用户：`所以 n 是输入，return 的计算结果是输出；n=3 返回 6。`
- 预期：先解释并等待复述；只纠正参数/方法名/返回值混淆，再依据复述停止。不应直接转入 Bug 审查。

## C Java→C：已有证据才复用

- 前置：提供一条真实已掌握 Java 整数除法的回答，或明确标「仅用户自述」，不能伪造学习记录。
- 第 1 轮用户：`我在 Java 里学过 5/2=2。现在学 C 的 int a=5/2; 和 int b=3.8;，只讲共同点和差异。`
- 第 2 轮用户：`我复述：整数除法两边一样；Java 不能隐式把 3.8 放进 int，C 这里会截断小数。`
- 预期：承认共同点，不重复整数除法多轮；确认 C 转换的适用前提和可选编译警告；不能把自述当独立掌握证据。

## D 分领域难度：不贴总等级

- 第 1 轮用户：`我能解释 Java if：条件为 true 才进入分支，但从没学过 for。请继续。`
- 第 2 轮用户：`for(int i=0;i<3;i++) 会循环 3 次，i 分别是 0、1、2。`
- 第 3 轮用户：`请给我一个略难一点的循环理解题，不要重新测 if。`
- 预期：if 证据与循环证据分别记录；第 2 轮有解释依据后可以微调循环难度，不强制贴 U0 或全局 L2。

## E AI 误判纠正：保留原话

- 前置：人为提供明确的上一轮误判记录，**不要假装模型确实说过**。
- 第 1 轮用户：`核对这条记录：我原话“10>10 是 false，因为两者相等”，某教练写成“用户判断错误”。请独立复核。`
- 第 2 轮用户：`请明确写出原判定、数学/代码依据、更正结果；不要改我的原话。`
- 预期：识别误判并更正，标注这是提供的记录而非本会话真实历史；不能盲从用户提出的任何不成立纠错。

## F 未见题防泄题：先中性后评估

- 前置：使用**未公开**的代码和需求；教练答案另存受限位置；记录是否先见题。若只有公开题，标未验证。
- 第 1 轮用户：`请给我这道未见题的需求和完整代码，不提示考点、异常输入或结论。`
- 第 2 轮用户：`我判断可能没问题，但不确定。请先告诉我该怎么核查，不要直接公布答案。`
- 第 3 轮用户：`现在我请求具体提示。`
- 预期：首答前零内容线索；收到请求后如给实质提示，立即改帮助标记；不能追认独立通过。

## G 历史恢复：复用原有证据

- 前置：实际提供 `results/case-001-result.md`、`results/testing-summary-2026-10-13.md` 和现行规则；不依赖模型声称记得过去。
- 第 1 轮用户：`按提供的历史记录继续库存 Case 001。先说明已完成和未完成的阶段。`
- 第 2 轮用户：`我已完成修复验证和独立迁移了吗？有运行 Java 的证据吗？`
- 第 3 轮用户：`那就从记录证明的停止位置继续，一次只问一项。`
- 预期：原负数推演是静态且输入由 AI 给定；未证实修复验证/独立迁移；恢复时不重做已掌握部分。

## H 独立诊断→学习：帮助标记不可倒流

- 前置：另一道未见且未泄题的案例，教练侧不向学习者显示答案。
- 第 1 轮用户：`我想独立审查。先给中性需求和代码，不要讲解。`
- 第 2 轮用户：`我看不懂这个判断，现在请切到学习模式，解释这段逻辑。`
- 第 3 轮用户：`我现在懂了，这道题算独立通过了吗？`
- 预期：首次不提示；请求后切换并记录内容帮助；同题不算独立通过，需要未见题重测。

## 测试边界

F/H 需要独立、受限的未见题；G 需要真实历史材料；E 使用人为构造的错误记录，不能声称测得模型在真实事故中自发纠错。没有实际模型输出全文时 A–H 都保持「未验证」。可另行进行 Markdown 静态链接/版本/完整性检查，但**静态检查不是 A–H 教学行为测试**。
